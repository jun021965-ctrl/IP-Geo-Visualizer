# IP-Geo-Visualizer
IP‑Geo‑Visualizer 是一个面向学生与初学者的轻量级通信可视化工具。它通过公共 IP 定位 API 获取 IP 的国家、城市、经纬度与运营商信息，并使用交互式地图将结果可视化，便于做网络测量、ISP 分布演示或课程作业演示。项目依赖少、易上手，适合在本地运行并直接上传到 GitHub 作为课程成果展示。  主要功能 单 IP 查询 — 输入任意 IPv4/IPv6，返回地理位置与运营商信息。  交互式地图 — 在浏览器中打开 HTML 地图并查看标注与弹窗信息。  国内稳定 API — 默认使用对国内网络友好的 IP 定位服务以避免 SSL 问题。  易扩展 — 支持批量查询、延迟测量（ping）与热力图扩展（后续可加）。
