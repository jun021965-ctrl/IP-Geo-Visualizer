
主要功能
单 IP 查询 — 输入任意 IPv4/IPv6，返回地理位置与运营商信息。

交互式地图 — 在浏览器中打开 HTML 地图并查看标注与弹窗信息。

国内稳定 API — 默认使用对国内网络友好的 IP 定位服务以避免 SSL 问题。

易扩展 — 支持批量查询、延迟测量（ping）与热力图扩展（后续可加）。

技术栈与依赖
语言：Python 3.9+

主要库：requests（HTTP 请求），folium（地图可视化）

可选工具：Git、GitHub（仓库托管）、PyCharm（开发）
